Security & FAQ

Collect is a preview. Sending is disabled. No app can guarantee protection against every attack or loss.

Can Collect move my funds?

This version does not request transaction signatures, token approvals or swaps from your wallet. Connecting shares your public account address; it does not approve token spending. Collect never asks for your seed phrase or private key.

What does Collect check?

Before preparing a plan, Collect refreshes selected balances on Base and checks the requested amounts. It checks unsigned calls against those amounts, the recipient, the Aerodrome router, the route and the expiry. Changes to your account, network or selection invalidate the current preview.

New approvals in a plan are limited to the planned amount. Existing sufficient allowances are left unchanged. Plans contain a minimum output and expire quickly. These checks do not prove that a token is safe.

Does “Sequence simulated” mean it is safe to send?

No. It means the simulated sequence completed and met the minimum USDC output. It checks selected token debits, router allowances and net USDC. It does not verify every asset, actual wallet execution or the full network fee. Approvals precede one router transaction containing the swaps. Prior approvals remain after a failed swap; gas is still spent. Sending is disabled.

Why might Rabby show a warning?

A wallet may warn that a site is unfamiliar or has little usage history. Those warnings are separate from checks on a transaction. Read the specific warning before proceeding; do not ignore it just because the site displays security information.

Collect uses Base. Check the network shown in your wallet. A listing, logo or personal label is not a security guarantee.

Which wallets can I use, and who sees my address?

You can choose a detected browser wallet, such as Rabby, or paste a public address without connecting. A Coinbase account is not required. WalletConnect and every wallet or mobile environment have not been verified.

Collect’s server and Base RPC providers receive the address for balance reads, quotes and simulations. Blockscout receives it for automatic token discovery. Disconnecting locally does not revoke existing wallet permissions or token allowances.

What does “Worth collecting?” mean?

After a successful basket simulation, Collect estimates separate approval and swap fees on Base, including L2 execution, L1 data and operator fees. It converts the estimated ETH cost to USDC using a current Aerodrome WETH/USDC quote. The result can change before execution. If any fee or price input is unavailable, Collect shows “Unknown”. It is not a guaranteed payout or a recommendation to sign.

How does “Compare what to include” work?

Collect tests the full selection and each option made by leaving out one token. Every option gets its own complete quote, sequence simulation and network-fee estimate at one shared Base block. It ranks only verified options with comparable, unexpired fee inputs. This is a sampled comparison, not a search of every possible subset or a guaranteed payout. Missing routes and failed simulations stay visible; sending remains disabled.

Has Collect been independently audited?

No. The application has had an internal code review and automated checks, including tests for altered amounts and calls. It also limits API requests and restricts which scripts and connections its pages can load. These are safeguards, not a certification or a guarantee against phishing, service disruption, malicious tokens or losses.
