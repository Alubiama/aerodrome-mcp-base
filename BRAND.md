# Aerodrome MCP visual identity

Independent community tooling for Aerodrome on Base. Not affiliated with Aerodrome or Base.

The official [Aerodrome Brand Kit](https://aerodrome.finance/brand) and live website informed this design. Observed website colors: navy `#090e1f`, blue `#2660f5`. Other shades, layout and illustrations are our own adaptation, not official brand guidelines. The demo uses a local Inter/Arial/sans-serif stack; no official font is bundled.

Our original [banner](docs/assets/banner.svg) and [icon](docs/assets/icon.svg) are project artwork under this repository's MIT license. They are not Aerodrome logos. Keep the independent-project disclaimer alongside promotional use. Do not imply endorsement, audits, guaranteed returns or transaction execution.

MCP clients may display the server title and icon differently or omit them. The stable server name and tool identifiers remain unchanged.
